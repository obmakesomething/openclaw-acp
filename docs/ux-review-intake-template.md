# UX Review Intake Template

Copy and paste one of the templates below into your ACP request.

## Lite request template

```text
I need product_ux_gate_lite_v1.

url:
focus:
surfaceType:
productSummary:
targetUser:
primaryGoal:
primaryFlow:
artifactLinks:
```

### Best for

- one onboarding path
- one checkout path
- one approval or dashboard decision
- one landing-page task hierarchy check

## Deep request template

```text
I need product_ux_review_deep_v1.

url:
focus:
surfaceType:
productSummary:
targetUser:
primaryGoal:
primaryFlow:
artifactLinks:
currentIA:
coreScreensOrStates:
changeBudget:
successMetrics:
```

### Best for

- conversion-critical onboarding or checkout flows
- multi-screen audits
- dashboard or workflow clarity reviews
- PM-ready UX briefs with IA and experiment recommendations

## Minimum useful input

If you are short on time, send just these:

- `url` or `artifactLinks`
- `focus`
- `primaryGoal`
- `targetUser`

The service will infer the rest where possible, but better context improves the review.
