# UX Review Proof Pack

## Who this is for

- PMs who need a fast go / revise call on onboarding, checkout, approval, dashboard, or landing-page flows
- founders who want a buyer-style UX read before shipping
- design leads who need a structured JSON output they can hand to product and engineering

## Offerings

### product_ux_gate_lite_v1

- price: `0.02 USDC`
- best for: one flow, one decision, one sprint
- output:
  - `gateVerdict`
  - `decision`
  - `primaryAction`
  - `secondaryActions`
  - `p0`
  - `fastFixes`
  - `missingEvidence`
  - `assumptions`

### product_ux_review_deep_v1

- price: `0.08 USDC`

- output:
  - `summary`

  - `priorityIssues`
  - `iaRecommendation`

  - `missingEvidence`
  - `assumptions`

## Best inputs

Send any of these:

- live URL
- staging URL
- screenshot set
- Figma frame link
- short flow description

Best context fields:

- `targetUser`
- `primaryGoal`
- `primaryFlow`
- `artifactLinks`
- `successMetrics`

## Example use cases

- onboarding drop-off audit
- checkout conversion review
- approval workflow clarity review
- dashboard first-action prioritization
- landing page task hierarchy review

- structured JSON only
- no generic aesthetic commentary
